# 跨媒体与一般日历时期补样

## v3 增补与质量复查（2026-11-04）

本轮在已交付 v2 的 116 条记录后增补，原文件及逐条审核字段保持不变。当前交付统计以 [v3 报告](data-expansion-report-v3.json)为准，取样修订保存在 [增补计划](data-expansion-supplement-plan.json)。原 v2 计划、报告和阅读页均保留作历史快照。

日期窗口保持原样；本轮将“Global Voices / VOA 各 8 条”扩展为“每窗口合计 16 条的多来源候选面板”。**窗口总量完成不等于原两家媒体的配额完成**，报告分别列出两种缺口。来源便利性、语言和体裁仍有选择偏差，不能将这批样本当作媒体总体的代表性抽样。

新增来源包括 African Arguments、Common Dreams、ISS Today、Middle East Monitor、Mongabay、GroundUp。新闻、评论及机构分析分别保留体裁；机构未署名稿明确记录署名状态，合作采写记录合作来源。引用 Reuters 等报道不代表独立事实验证；发现整篇通讯社来源、未能核实日期或许可的候选不入选。The Conversation 的候选保留待核实原因，未计入已完成的来源覆盖。

质量复查发现，标题或前 800 字内出现地名仍可能只是名单或历史类比，因此本轮新增统一要求标题命中中性地域/主体名。刚果和加沙候选还要在标题/导语具有对应国家或地区语境；红海候选必须包含也门或胡塞语境。此方法提高筛选精度，但会漏掉标题不写地名的真实相关报道。它不是人工双边关系标注。所有额外范围排除见 [筛查决定](data-expansion-screening-decisions.json)，不使用模型分数或行动结果筛选。

来源及月份轮流抽取，同条件按固定 seed 的 SHA-256 排序。新样本与旧样本、train/validation 的 URL、正文和标题比较；以 5 词 shingle 的包含率 ≥ 0.65（同时覆盖 Jaccard ≥ 0.5）排除强近重复。不同措辞的同一事件仍可能保留，未来必须按故事/事件、案例及时间分组，不能将不同 URL 当作独立事实。

本轮已修正推荐文章标题、图注、语言导航、重刊政策混入正文的问题，并补对应测试；重新解析都使用已缓存网页，不擅自改写原文。网页修改日期照实保存：当前抓取版本不等于发表当日版本，所有历史快照验证标记仍为 `false`。

另有 **4 条原 v2 记录列入优先隔离审核清单**：3 条刚果范围误召回，以及 1 条苏丹声明的共同来源、原发日期和红海范围疑点。详见 [有证据的质量问题](data-quality-findings.json)。旧记录保留供审计，**不得把这 4 条计为已验证案例覆盖**；报告同时给出扣除这 4 条后的库存数，仍不代表其他记录已获人工认可。

各篇保留作者、来源、正文引用链接、许可证及原始缓存。ISS Today 站点 CC BY 4.0 条款与专栏转载说明并存，单独保留 `reuse_caveat`，本次只在本地整理。GroundUp 已于 2026 年改变新稿许可，本次依据 2024 年文章仍保留的逐篇 CC BY-ND 4.0 声明及旧许可保留说明，不能把它扩用于全站新稿。没有对外发布全文。

## v2 历史记录

这批数据补充新闻来源和非事件倒推的时间窗口，供下一轮人工审核。**“一般日历对照”是采样方式，不是“和平时期”或负标签。** 当前全部 `labels: null`、`review_status: pending`、`split: unassigned`，不参与现有模型训练，也不改变固定的 60 篇审核新闻。

首批共整理 **116 个案例—新闻组合、115 篇独立新闻**：原窗口跨媒体 55 个、一般日历对照 61 个；Global Voices 63 个、VOA 53 个。预设 160 个组合中有 **44 个配额缺口**，主要集中在刚果和红海相关窗口，未用转载、无关文章或更换日期凑数。另有 1 篇新闻关联两个主题，报告中保留共同内容组。

交付前的来源复核修正了多语种作者主页核验，并补充明确转载、媒体合作声明的识别。最终版本记为 v2，使用同一缓存候选池，时间窗口、seed、配额和标签规则不变；初步 v1/v1.1 稿及报告只保留作本地审计，不作为本次最终数据。

## 采样范围

计划与 seed 保存在 [data-expansion-plan.json](data-expansion-plan.json)。研究对象为现有 S016–S020 的五个主题：叙利亚、刚果（金）/M23/卢旺达、美国/胡塞/红海、以色列/加沙、印度/巴基斯坦/克什米尔。

- **同窗跨媒体层**：每个主题使用原验证案例的日期范围，补入其他编辑部的英文报道，减少媒体与时间差异混杂。
- **一般日历对照层**：五个主题统一采用 2024-01-01 至 2024-03-31。它没有按某次事件发生日向前倒推；该期间若发生战争或袭击，照样保留，不能为了制造负例删文。
- 每个“主题窗口 × 媒体”目标 8 条，总目标 160 个案例—新闻组合。正文取得后，按月份轮流抽取，各月内部按固定 seed、窗口、媒体、规范 URL 的 SHA-256 排序。没有使用行动关键词、模型得分或正负标签选文。
- 搜索词只有计划中的国家、地区和主体名。API 的宽搜索结果必须在实际标题或正文中出现对应中性词；`Red Sea` 必须是连续短语，不能由分散的 `red` 和 `sea` 拼成命中。命中检索词仍不等于满足双边关系或事件范围，相关性需人工判断。
- 相同正文规范化后去重，不用转载补足配额；与既有开发新闻完全同文的记录不算新增。不同案例关联同一新闻时保留共同内容组，不能把组合数当独立新闻数。

## 来源、可取得范围与归属

| 来源 | 发现与正文路径 | 取得限制 |
| --- | --- | --- |
| Global Voices | 官方 WordPress API 按日期和中性词分页枚举，公开正文页核验作者 | 既有新闻报道也有评论、文化和社会议题；带第三方整篇转载声明或无法核实署名的记录排除 |
| Voice of America | 固定 sitemap 1–6；按 URL 中性词及 sitemap `lastmod` 发现，每窗口按月份/哈希预选最多 30 条，再读取文章 JSON-LD 和正文 | `lastmod` 不是发表日期，仅用于候选发现；实际日期必须再次核验。此路径不是历史媒体全文的穷举，URL 没有国家名或后来更新的文章可能漏掉 |

Global Voices 的[转载政策](https://globalvoices.org/about/global-voices-attribution-policy/)允许按 [CC BY 3.0](https://creativecommons.org/licenses/by/3.0/)使用其原创文字，需保留作者和原链接。VOA 的[来源政策](https://www.voanews.com/p/5338.html)区分原创公共领域文字与第三方版权内容。本批只保存符合对应来源条件的纯文字，排除 AP、Reuters、AFP 署名或明确通讯社贡献的 VOA 稿件，不下载图片、音视频或嵌入媒体。

每篇保存规范 URL、媒体、编辑来源、作者与作者页、发表日、修改时间、抓取时间、许可依据、外部引用链接、正文 SHA-256。处理仅包含提取正文、去除媒体/图注及空白规范化；不是用模型重写新闻。

## 缺失、审阅与使用边界

配额不足、抓取失败、无法验证作者、第三方转载、日期不符、无可用正文等均保留记录。不得将这些情况记为 `action: false`，也不在看到结果后换成更容易取得的日期补位。

两家可访问来源组成的是便利来源面板，不能代表 Reuters、AP、BBC 等媒体总体。Global Voices 的体裁和 VOA 的机构背景也有各自偏向，后续应分别报告媒体、体裁和研究对象的识别结果。不同域名不保证事实证据独立，同一通讯社、被引用消息或同一事件仍需聚类审查。

新抓取的是历史新闻的**当前网页版本**，并不自动等于发表当日可见文本。`historical_snapshot_verified` 保持 `false`，另记录是否在发表日之后修改；进行严格时间回测前须核实存档版本及可用时点。

以下工作仍需完成：人工相关性与事件标注、一般日历样本中真正负例的核实、稀缺主题的其他媒体补采、同一新闻/事件及时间的分组划分、独立未来事件真值建立。没有完成这些工作前，不能用这一批未标注样本宣称准确率改善，或直接合并重训。

## 本地文件与复现

```sh
node scripts/collect-globalvoices.mjs
node scripts/collect-voa.mjs
node scripts/prepare-expansion.mjs
node --test
```

采集需要网络；只读取新闻网站，不发送本地新闻、审核记录或模型。缓存和全文保存在被 Git 忽略的 `local-data/expansion/2026-11-04/`：

- `globalvoices-candidates.jsonl`、`voa-candidates.jsonl`：候选与排除记录。
- 两个来源的缓存与采集日志：来源发现和正文解析的审计依据。
- `samples-calendar-source-expansion-v2.jsonl`：本次最终冻结选中的待审核案例—新闻组合；此前的样本文件仅作为修正前审计记录。
- `catalog.html`：可按媒体和采样层筛选、展开全文的本地阅读入口。

[data-expansion-report.json](data-expansion-report.json)记录实际条数、各窗口配额缺口、共享正文组、来源文件哈希和每条选中样本的链接。重复整理会拒绝更换既有样本，或覆盖已经填写的审核结果；需要扩展时另建版本。

固定 60 篇的 Excel 是现有开发识别评估的人工填写入口，新增样本单独管理，避免更改原评估集。五项判断必须由真实审核者填写；不确定不能等同于“否”，初审不展示模型输出。标签定义与裁决规则仍见 [evaluation-protocol.md](evaluation-protocol.md)。
